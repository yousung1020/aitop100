## 2. 출처를 더 확인해야 하는 정책·사실

### 박민아 역할과 운영 대체 경로

기존 권한 위임 요약에는 이민준 부재 시 구방만 → 박민아 대체 확인 경로가 기록되어 있고, 최신 박민아 인터뷰에는 냉동탑차 TR-GM-02 기사로 기록되어 있습니다. 동일인의 겸임인지, 기존 요약의 역할 해석 오류인지는 확보 자료만으로 확정하지 않았습니다. 원문 기록은 보존하며 기사에게 새로운 보상·정책 승인권을 부여하지 않습니다. 업무상 확인 경로와 승인권은 같은 개념이 아닙니다.

### 당도 미달 로트의 출고 여부

일반 지식 요약에는 “기준 미달 로트는 고객에게 발송되지 않는다”는 품질관리 원칙이 있으나 공식 R-05-a는 기준 미달 로트가 실제 출고된 사고 사례입니다. 미달 출고는 불가능하다는 이유로 고객 신고나 공식 로트 조회 결과를 배척해서는 안 됩니다. R-05-a의 상품 상세페이지는 재배송·환불 선택권을 명시합니다. 일반 규정의 최초 재배송 절차만으로 해당 사례의 환불 선택권을 제거하지 않습니다.

### 무게 판정 문구

수산물 세칙 요약의 “8% 초과 여부의 계산은 실결제액 기준”은 중량 비율 판정과 환불액 산정을 혼동할 수 있습니다. 원문 재확인이 필요합니다. 중량 판정에 결제액을 대입하는 새 공식을 만들지 않으며, 공식 규격 미달·자연감량 규정과 실제 출고 기록을 대조합니다.

### 공식 TC에서 추가 확인된 정책

L-47은 정상가 인하 차액 4,100원에 CARE5000 발급 접수·발급일부터 90일 유효·현금환불 미호출을 명시합니다. L-20·L-60은 SUBAK15·일반 할인/보상 쿠폰 중복 조건, L-40은 반복 대량 구매의 소매 혜택 제한을 명시합니다. 이 사례 조건을 전체 상품·고객에 무조건 확장하지 않고 상품·프로모션·거래 정책 원문을 함께 확보합니다. Y-24에 필요한 실제 판매자 공시 값은 사례 문서에 없으므로 별도 공시 원본이 필요합니다.

### 대회 전체 일정·배점·실격 세부 기준

기존 SPECIFICATION의 32시간 운영 종료 시각, 가중치 40/20/15/15/10, 30건 평가 전체 구성, 동점 처리 순서 등은 현재 보관된 공식 액션 API·공개 TC만으로 검증할 수 없습니다. 해당 문서에 출처 재확인 상태로 표시하며 공식 확정 사실로 단정하지 않습니다. AGENTS의 SimpleText·글자 수·타임아웃 가드레일은 프로젝트 작업 제약으로 유지합니다. 실제 제출·운영 전 참가자 안내 원문으로 일정과 변경 금지 범위를 확인해야 합니다.

## 3. 구현과 문서 간 남은 차이

수정 후 229개 테스트는 통과했습니다. 그러나 레거시 결과에 의존하는 이관 처리, 배송 조회 실패 후 주소 변경 접수, Mock의 즉시 주소 변경·접수번호 비멱등성, 공개 TC별 미연결 처리 흐름이 남아 있습니다. 상담일·인입 계정·히스토리는 저장만으로 실제 판단에 활용됐다고 볼 수 없습니다. 실제 Chrome의 공식 API 원문은 기존 스냅샷과 동일하므로, 이는 공식 문서 변경이 아닌 구현·검증 범위의 차이입니다. 상세 근거는 [재확인 기록](API_CONSISTENCY_AUDIT.md)을 참조합니다. 인터뷰 동기화 체크리스트의 기존 `[x]`도 작성 당시 정형화 반영 기록이지 공식 TC 전수 통과 증명이 아닙니다.
