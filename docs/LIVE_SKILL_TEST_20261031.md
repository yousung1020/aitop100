# 실제 HTTPS 스킬 테스트

대상: `https://pulled-mounts-bug-enabled.trycloudflare.com/skill`.
실행일: 2026-10-31. 정확한 UTC 시작·종료 시각과 케이스별 요청·응답은 [결과 JSON](source_materials/live_skill_test_20261031.json)에 기록했습니다. 테스트 설계와 응답 내용 대조는 서브 에이전트가 독립 검토했습니다.

## 1. 범위 및 결과

실제 HTTPS 스킬에 서로 다른 가상 사용자로 POST 12건을 보냈습니다. 주문번호·회원 ID·상세주소를 제공하지 않았으며, 환불·쿠폰 발급·주소 변경·이관·재배송 접수 및 초기화는 요청하지 않았습니다. L-60은 프로모션 조건 조회, Y-24는 안내 전용 문의입니다. 서버의 액션 감사 로그를 확인한 것은 아니므로 외부 액션 부재를 서버측 기록으로 증명한 결과는 아닙니다.

| 항목 | 결과 |
| :--- | :--- |
| HTTP 200 | 12/12 |
| SimpleText 1개·빈 답변 없음·500자 이하 | 12/12 |
| 후처리 목표 480자 이하 | 12/12, 최대 405자 |
| HTTPS 왕복 5초 미만 | 12/12 |
| 전체 평균·최대 | 1.409초·2.634초 |
| 일반 문의 10건 평균 | 1.644초 |
| 빈 발화·잘못된 본문 | 모두 HTTP 200과 텍스트 폴백 |
| 카드·버튼 응답 유도 | SimpleText 유지 |

측정은 순차 요청의 작은 표본으로 네트워크 왕복을 포함합니다. 실제 카카오톡 채널 p95나 모델 호출 성공 여부를 증명하지 않습니다. 로컬 확인 시점 커밋은 `b8b6544`이나 원격 실행 커밋은 확인하지 않았습니다.

### P1 — 배송비 정책 충돌

합포장 문의에 교동 5만원·갯마을 7만원 이상 무료배송이라고 추가 안내했습니다. 확보된 [상품 상세 원문](source_materials/product_detail_pages_extracted.txt)은 수박 배송비 4,000원과 금액별 무료배송 미운영을 명시합니다. 최소한 해당 수박에 무료배송 기준을 무조건 일반화하면 원문과 충돌합니다. 기존 인터뷰·프롬프트와 상품 조건의 적용 범위를 대조해야 하며, 이번 테스트에서 새로운 정책 우선순위를 결정하지 않았습니다.

### P1 — 출처 없는 판매자 공시 정보 확언

Y-24 답변에 대표자 `양정환`, 사업자번호·제주 주소·고객센터 번호가 등장했습니다. [공식 Y-24 원문](source_materials/policy_research_20261031/Y-24.md)은 공시 항목을 나열하지만 실제 값을 제공하지 않습니다. [정책 조사](POLICY_AND_SUBMISSION_RESEARCH.md)에서도 공시 원본은 미확보입니다. 현재 코드의 고정 값을 모델이 공식 공시로 되풀이한 것으로 보이며, 원문 확보 전 해당 정보를 사실로 안내해서는 안 됩니다.

### 추가 확인 사항

- SUBAK15 답변은 할인 중복의 핵심은 맞지만, 공식 L-60의 수박 한정 15% 및 2037-06-26~07-03 기간을 빠뜨렸습니다. 전체 모범 처리 통과로 집계하지 않습니다.
- 잘못된 본문 `{}`에 대한 폴백에는 `data`, `context`가 null로 남습니다. 정상 응답에서는 제외됩니다. `app/main.py`의 예외 핸들러가 `model_dump()`를 그대로 사용하므로 직렬화가 다릅니다. 이 차이만으로 SimpleText 위반이나 카카오 채널 거절을 단정하지 않습니다.

## 3. 제한 및 후속 검증

이번 테스트는 사용자 발화가 카카오톡을 거쳐 전달되는 E2E가 아니라 HTTPS 스킬 직접 호출입니다. 처리 의사 확인·동일 사용자 멀티턴·접수 POST·실제 환불/발급 등은 별도 검증 범위입니다. 해당 검증에는 공식 계약 및 기존 리뷰의 안전성 결함을 먼저 반영해야 합니다.

앱 코드·프롬프트·배포 설정은 수정하지 않았습니다. 토큰이나 실제 고객 정보를 결과에 저장하지 않았습니다.
