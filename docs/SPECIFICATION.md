# 대회 규격 및 확인 상태

갱신일: 2026-10-31. 공식 액션 문서·공개 TC로 확인한 사실, 프로젝트 작업 제약, 출처 재확인이 필요한 기존 주장을 구분합니다. 문서 정리만으로 대회 규정을 새로 확정하지 않습니다.

## 1. 확보한 공식 자료

로그인된 대회 문서에서 업무 API 40개와 데이터 초기화 API, 요청·응답 스키마 50종 및 공개 TC 15건을 확인했습니다. 상세 내용과 출처는 [API 규약](API_AND_PROTOCOLS.md), [스키마](ACTION_API_SCHEMAS.md), [공개 TC](PUBLIC_TEST_CASES.md)에 보관합니다.

공개 TC 15건은 평가 전체 건수를 의미하지 않습니다. 자체 30건 시뮬레이션은 프로젝트 계획이며 아직 하네스와 실행 결과가 없습니다. 공식 업무 POST는 실행 완료가 아닌 요청 접수이며, 정책 타당성 판단은 에이전트가 담당합니다.

## 2. 프로젝트의 필수 응답 제약

[AGENTS.md](../AGENTS.md)에 따라 다음 제약을 유지합니다.

- SimpleText 단일 말풍선으로 답변합니다. 버튼·카드·이미지·분할 발송을 사용하지 않습니다.
- 말풍선은 500자 이하이며 후처리 목표는 480자입니다.
- LLM·비동기 처리의 최대 제한은 15초 이내로 두며, 현재 운영 요청의 내부 타임아웃 설정은 일반 스킬 5초 대비 4.5초입니다.
- 정책·액션 계약·배포 인프라에 대한 미확인 선택은 사용자에게 확인합니다.

가드레일 구현과 실제 채널의 응답 시간·정확도 검증은 별개입니다. 테스트 결과는 [HANDOFF.md](../HANDOFF.md)에 기록합니다.

## 3. 출처 재확인이 필요한 기존 주장

이전 문서는 다음 항목을 “공식 확정”으로 표기했으나, 현재 보관한 공식 액션·TC 자료만으로는 근거를 확인할 수 없습니다. 제출·운영 전 참가자 안내 원문과 대조해야 합니다.

| 기존 기록 | 현재 취급 |
| :--- | :--- |
| 10월 31일 09시 준비, 10~15시 구현, 15시 제출 마감 | 정확한 제출 시각·규칙 원문 재확인 필요 |
| 10월 31일 16시~11월 1일 24시, 32시간 심사 | 평가 기간·종료 시각 재확인 필요 |
| 제출 후 모든 코드·설정·도메인 변경 및 재시작 금지, 즉시 실격 | 변경 금지의 실제 범위·예외·제재 원문 재확인 필요 |
| 평가 30건 및 유형별 8/7/5/4/3/3건 구성 | 내부 예상 분류로만 취급. 공식 전체 구성으로 사용하지 않음 |
| 정확도/지식/지연/글자 수/말풍선 배점 40/20/15/15/10 | 공식 배점·계산식 미확인 |
| 답변 150~350자가 최적 점수 구간 | 공식 최적 구간 미확인 |
| 60초 초과 또는 500자 초과 10건 누적 실격 | 누적 횟수·실격 판정 원문 미확인. 프로젝트 제한은 유지 |
| 카드 응답 즉시 0점, 동점 시 정확도→지연→지식→말풍선 순 | 세부 제재·동점 처리 기준 미확인 |
| 심사위원 3인 페르소나 | 내부 대비용 가정이며 공식 심사 구성 미확인 |

미확인 항목을 근거로 배포 인프라나 정책을 새로 선택하지 않습니다. 관련 해석 문제는 [정합성 문서](CONSISTENCY_NOTES.md)에 기록합니다.
