--- SHEET: 4. 확인 범위 ---
4. 확인 범위 |  |  |  |  | 
월 단위 시즌표로 확정 입고일·출고일·도착일을 약속하지 아니한다. 기상·조업 사실과 판매 상태를 구분하여 확인한다(「달력/날씨 이력」·「품목별 SKU 카탈로그(1차 6종 + 수산물)」·「갯마을 조업·입고 기록」). 이미 출고된 냉동 상품의 보관·상태·안전 문의는 성어기 여부와 무관하게 답한다. 보관 조건과 상품 기준은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」를 따른다. |  |  |  |  |
