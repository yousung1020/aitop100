- 기존 상품 상세페이지·판매/환불 규정집은 공개 CDN에서 다시 받아 보관본과 비교했습니다. **두 문서 모두 바이트 단위로 동일**합니다.

업무 API 조회·접수·초기화, 제출·임시저장, 관계자 메시지 전송은 수행하지 않았습니다. 토큰·쿠키·입력란 값은 수집하지 않았습니다.

## 3. Y-24 판매자 사업자 공시

[Y-24 원문](source_materials/policy_research_20261031/Y-24.md)은 공시된 상호·대표자명·사업자등록번호·사업장 주소·대표 전화 또는 이메일을 안내하도록 요구합니다. 상황 설명에는 통신판매업 신고번호도 공시 항목으로 기재되어 있습니다. 대표자 사생활·가족관계·매입가·계약조건은 별도 비공개 범위입니다.

**실제 공시 값과 공시 페이지 URL은 여전히 미확보입니다.** 다음을 확인했습니다.

- Y-24의 원문·페이지는 공시 항목을 나열하지만 번호·주소·연락처의 실제 값을 제공하지 않습니다.

- 개인정보 처리방침 제17조는 공개 범위를 설명할 뿐 사업자 공시 값을 대신하지 않습니다.
- 대회 운영사의 사업자정보나 연락처는 세계관 속 조합몰 판매자 정보의 근거가 아닙니다. 이를 대입하지 않습니다.

### 연동 규격 확인이 필요한 사항

참가자 가이드는 **카카오디벨로퍼스 앱의 카카오톡 봇** 생성·연동과 [봇 REST API](https://developers.kakao.com/docs/ko/bot/rest-api)를 안내합니다. 기존 프로젝트의 카카오 i 오픈빌더 스킬 JSON이 평가 대상 봇과 바로 호환된다는 근거는 이 안내만으로 확정할 수 없습니다. 실제 평가 대상 App의 봇 설정과 송수신 계약 대조가 배포 전 필요합니다.

해당 카카오 문서 링크는 이번 웹 도구에서 열리지 않았고 직접 GET도 404였습니다. 상세 REST 송수신 계약을 확인한 것으로 처리하지 않으며, 기존 웹훅의 변경도 수행하지 않았습니다.

## 5. 평가 기준과 기존 주장 정정 근거

공식 기준은 인터뷰 지식 수, p95 응답 속도, 평균 말풍선 수, 말풍선당 평균 글자 수, 케이스 응답 정확도의 5개 항목입니다. 속도·말풍선 수·글자 수는 정확도 점수에 따라 가중치가 적용됩니다. **배점 비율과 세부 계산 로직은 공개하지 않습니다.** 따라서 과거의 40/20/15/15/10 배점은 공식 근거로 사용할 수 없습니다.

AGENTS에 있는 “60초 타임아웃 10건 누적 시 즉시 탈락” 설명은 이번 공식 원문과 다릅니다. 원문은 60초 무응답 종료와 케이스당 응답 10건 제한을 각각 규정합니다. **AGENTS의 단일 SimpleText·500자 상한·480자 후처리·내부 4.5초 제약은 변경하지 않았습니다.** 평가 규칙의 사실관계와 프로젝트의 보수적인 구현 제약을 구분해야 합니다.
